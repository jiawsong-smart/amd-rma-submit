# EPYC & INSTINCT RMA Submission

Customer form for MI INSTINCT GPU and EPYC CPU RMA details. Open `mi-rma-submit.html` in a browser. The page and `amd-logo.svg` must stay in the same folder.

Entries stay in that browser until Submit. Submit checks required fields, asks for confirmation, then downloads a HOTPOT Excel file. Send that file from your own mailbox. If the AMD contact email is left blank, the recipient is `dl.Arthur_Staff@amd.com`.

Do not commit filled customer RMA files, serial numbers, or exported workbooks to this repository.
